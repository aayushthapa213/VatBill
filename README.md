# VAT Bill / Invoice Generator

A small vanilla JavaScript app for creating bills with 13% VAT. Enter customer details, add as many products as you need, and generate an itemised invoice with subtotal, VAT, and grand total.

Built while revisiting JavaScript fundamentals: DOM selection, event listeners, dynamic elements, and template literals.

## Run it

No build step. Open `index.html` in a browser.

## Structure

```
index.html       # form and bill layout
css/style.css    # styles
script/main.js   # product rows, calculations, bill rendering
```
